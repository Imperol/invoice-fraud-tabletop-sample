# Invoice Fraud Tabletop — free three-minute sample

A short, fictional supplier-payment exercise for finance, IT and decision makers.
Read one situation, record a proposed response and review the decision with a
colleague. This repository contains the free sample of **Payment Under Pressure**,
not the complete 60-minute kit.

## The situation

A familiar supplier appears to change its payment instructions just before the
payment run. The invoice number and CHF18,600 amount match a genuine purchase,
but the requested destination differs from the supplier record. No independent
verification has been completed. All names, amounts and account labels are fictional.

Use the sample to discuss:

- Who can pause this payment, and how would the team confirm the hold took effect?
- How would you verify the request without relying on contact details in the message?
- What is known, what remains uncertain, and who owns the next action?

There is no score or claim that completing the sample proves an organisation secure.

## Download and try it

1. Download this repository using **Code → Download ZIP**, then unzip it. If you
   already have this folder locally, start with the next step.
2. Open [index.html](index.html) in a browser with JavaScript enabled. No server,
   installation, account, API key or internet connection is needed to run it.
3. Enter fictional notes, or choose **Fill an illustrative example**. Review the
   proposed decision and download the text record if you want to keep it.

The notes exist only in the current tab's memory. Refreshing or closing loses
those notes; check that your downloaded record was saved. There is no import,
cloud sync, tracking or background network request. External links open online
only when you select them. An optional [two-page PDF preview](invoice-fraud-preview.pdf)
is also included; it is an excerpt, not the complete facilitator guide.
