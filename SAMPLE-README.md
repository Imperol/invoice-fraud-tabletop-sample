# Invoice Fraud Tabletop — free three-minute sample

Try the opening supplier-payment decision from **Payment Under Pressure**.
This free preview includes one fictional scenario, a short decision form, a
review screen and a downloadable text record. It is not the full exercise.

## Open the sample

1. Unzip this folder if necessary.
2. Open `index.html` in a desktop or mobile browser with JavaScript enabled.
3. Read the situation, enter fictional notes (or use the illustrative example),
   then review and download your sample record.

The included `invoice-fraud-preview.pdf` provides a two-page printable preview.
It is optional; the interactive sample is `index.html`.

No installation, sign-up, server, API key or internet connection is needed to run
the sample. It has no external dependencies, tracking or background network
requests. The full-kit and reference links open online only when you choose them.

Your notes exist only in the current browser tab's memory. Refreshing or closing
the tab loses them. Download the text record and check that it was saved if you
want to keep it. The sample has no import or cloud-sync function.

## Scope

All scenario details are fictional. Discuss proposed actions only: do not contact
real parties, send messages, move money or change systems during this preview.
A filled decision record is not evidence that an action has been completed or
that an organisation is secure. No customer results are claimed.

The sample and full kit were developed with substantial AI assistance. They are
educational material, not certification, incident response support or a guarantee
of preventing fraud or recovering funds.
